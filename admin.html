Pindahkan / Cadangkan Data

Impor file pembaruan sebelumnya jika ingin melanjutkan pengeditan di perangkat lain.

Cara menerapkan hasil: klik “Ekspor Pembaruan Website”, lalu simpan file bernama site-content.js ke folder website dan pilih Replace/Ganti file lama. Unggah ulang file website yang telah diperbarui ke hosting agar pengunjung melihat perubahan. Dashboard statis ini tidak memiliki akun/login server; jangan menaruh data pribadi atau rahasia di dalamnya.
